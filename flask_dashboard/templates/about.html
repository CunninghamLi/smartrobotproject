About SmartPath

SmartPath is a Raspberry Pi powered robotic platform designed for live control, real-time sensor monitoring, and autonomous navigation.

What SmartPath Can Do

  • Live distance, line, and camera sensor monitoring
  • Manual driving with motor controls
  • LED and buzzer control through Adafruit IO
  • Line Tracking mode using infrared sensors
  • Obstacle Avoidance mode using an ultrasonic sensor
  • Flask dashboard for UI control
  • MQTT communication between the Pi and Adafruit IO

System Architecture

The robot communicates through Adafruit IO using MQTT. The Raspberry Pi runs a control program that receives commands (start, stop, speed, direction, mode) and drives the motors accordingly. At the same time, it continuously sends sensor data (distance, line state, camera status) back to the cloud.

Web Dashboard

The Flask dashboard provides a clean interface for controlling the car:

  • Control Panel for motors, LED, and buzzer
  • Pages for Line Tracking and Obstacle Avoidance
  • Live charts for sensor readings
  • Historical sensor graphs (database integration coming soon)
